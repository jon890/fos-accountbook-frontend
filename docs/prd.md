# PRD — fos-accountbook (우리집 가계부)

## 한 줄 정의

가족 구성원이 함께 수입·지출을 기록하고, 예산을 관리하며, 소비 패턴을 파악하는 가족용 가계부 웹앱.

---

## 문제

개인 가계부 앱은 많지만, **가족 단위로 함께 관리**하는 도구는 부족하다.

- 월세·관리비 같은 **반복 지출을 매달 수동 등록**해야 한다
- 남편/아내가 각자 기록하면 **한쪽 지출을 모른다**
- 카드 앱과 가계부가 분리되어 **이중 관리** 부담이 크다

---

## 타겟 사용자

- **주 사용자**: 가정 살림을 주도적으로 관리하는 구성원 (주부, 가계 담당자)
- **공동 사용자**: 함께 수입·지출을 입력하는 가족 구성원 (배우자, 동거인)

---

## 핵심 가치

1. **함께 관리** — 가족 초대 후 공동 입력, 서로의 지출이 실시간 반영
2. **예산 중심** — 월 예산 설정 → 진행률 시각화 → 초과 알림
3. **카테고리 분류** — 지출을 카테고리별로 분석, 패턴 파악

## MVP 범위 (현재 v1 기준)

### 포함된 기능

| 기능               | 설명                                                     |
| ------------------ | -------------------------------------------------------- |
| **OAuth 로그인**   | Google, Naver 소셜 로그인                                |
| **가족 생성/초대** | 가족 생성, 초대 링크 발급 (72시간 유효), 수락            |
| **지출 관리**      | 등록·수정·삭제, 카테고리·날짜 필터, 페이지네이션         |
| **수입 관리**      | 등록·수정·삭제, 카테고리·날짜 필터, 페이지네이션         |
| **카테고리 관리**  | 가족별 카테고리 CRUD, 색상/아이콘 설정, 예산 제외 플래그 |
| **대시보드**       | 월 지출·수입·남은 예산 요약, 최근 지출 목록              |
| **캘린더 뷰**      | 일별 수입·지출 시각화 (대시보드 내 차트)                 |
| **분석**           | 카테고리별 지출 분석, 비율 차트                          |
| **예산 관리**      | 월 예산 설정, 진행률 표시                                |
| **예산 알림**      | 80% 경고, 100% 초과 알림                                 |
| **알림 센터**      | 읽지 않은 알림 수, 읽음 처리                             |
| **사용자 설정**    | 기본 가족 선택, 프로필 (timezone, language, currency)    |

### 제외 (v1)

- 반복 지출 스케줄링
- 영수증 사진 첨부
- 데이터 내보내기 (CSV, Excel)
- 멀티 프로필 (동일 계정으로 여러 가족)
- 공유 링크 없는 가족 탈퇴

## v2 — 반복 지출 스케줄링

**Why**: 월세·관리비처럼 매달 같은 날, 같은 금액이 나가는 지출을 매번 수동 입력해야 한다는 페인포인트. 한 번 등록 → 자동 생성.

### 기능 명세

| 기능               | 설명                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **반복 지출 등록** | 이름(필수)·카테고리·금액·매월 N일(1~28) 입력. 등록 당일은 제외, 내일부터 적용            |
| **자동 지출 생성** | 매일 새벽 1시 스케줄러 실행. 해당 일자인 ACTIVE 템플릿 → Expense 자동 생성               |
| **고정지출 탭**    | 거래내역 3번째 탭. 이번달 합계 + 템플릿 목록(day_of_month 오름차순). ✓=생성완료 / ○=예정 |
| **대시보드 카드**  | "이달 고정비 OOO원" 카드 추가(기존 카드 아래 새 행). 클릭 → 고정지출 탭                  |
| **수정**           | 템플릿 즉시 변경 → 다음 스케줄러 실행부터 반영. "이번만 수정" 없음                       |
| **삭제**           | Soft Delete (ENDED). 이후 자동 등록 중단, 기존 생성 지출 유지                            |
| **자동 생성 표시** | 지출 탭에서 자동 생성 지출에 `RefreshCw` 아이콘(회색) 표시                               |
| **알림**           | 자동 생성 시 `RECURRING_EXPENSE_CREATED` 알림 (가족 전체, 읽음 처리만)                   |

### MVP 제약

- 매월 주기만 지원 (매주·매년은 v3)
- 29~31일 등록 불가 (월말 처리 복잡성 회피, v3에서 "마지막 날" 전략 검토)
- 서버 다운 시 해당일 누락 → 사용자 수동 등록 (복구 로직 없음)
- 권한: 가족 내 모든 MEMBER가 CRUD 가능

### 성공 지표

- 반복 지출 등록 30초 이내
- 대시보드 1뷰에서 이달 고정비 총액 파악 가능

## 성공 지표

- 지출 등록까지 3탭 이내 (카테고리 선택 → 금액 → 저장)
- 대시보드에서 이번 달 예산 소비 현황 3초 이내 파악 가능
- 가족 초대 → 수락까지 링크 1개로 완료
